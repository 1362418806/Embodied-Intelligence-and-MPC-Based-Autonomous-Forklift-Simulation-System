# 具身智能与 MPC 叉车仿真系统

平衡重叉车在 MuJoCo 里自主完成叉取、搬运和放置。车载双 RGB 负责看见叉孔和放置区，滚动规划把车送进作业走廊，局部运动学 MPC 做终端对位。位置、航向和新鲜视觉证据同时合格后，货叉才下降。货物的插入、抬升、搬运、下降和抽离都发生在刚体接触里。仿真真值只进入安全检查和成绩计算。

![仿真场景](screenshot.png)

## 功能

- MuJoCo 三维场景：平衡重叉车、Ackermann 底盘、独立货叉、托盘和货物
- 手动驾驶，以及手动 / 自动切换
- 双 RGB 检测叉孔和放置区，检测按置信度融合后进入控制
- 自主作业：接近、对位、插叉、抬升、搬运、核验、下降、抽叉
- 按随机种子批量运行，并分开统计任务完成和放置精度

## 算法

```text
双 RGB 检测
    ↓
载货状态估计
    ↓
滚动走廊规划
    ↓
局部运动学 MPC（约每 0.1 秒重规划）
    ↓
放货证据核验
    ↓
刚体接触结果 → 独立真值评分
```

姿态不适合直接修正时，控制器回退到有界的 S 形调整。运动过程中的载货航向和放货所用的航向证据分开保存。内部放货门限约为 9.5 cm、4.6°，对外按位置误差小于 10 cm、航向误差小于 5° 评判。

## 环境

开发环境为 Conda 环境 `forklift_sim`，Python 3.11，MuJoCo 3.11.0。需要可用的图形界面。依赖版本见 [`requirements-lock.txt`](requirements-lock.txt)。其中 `packaging` 一行指向本机 conda 构建路径，不能直接用这条锁文件在另一台机器上安装。

## 快速开始

在仓库根目录执行：

```powershell
conda activate forklift_sim
python .\scripts\run_forklift_v9_0_1_1.py
```

可选参数：

```powershell
python .\scripts\run_forklift_v9_0_1_1.py --config .\configs\vehicle_v9_0_1_1.yaml --perception-profile moderate --appearance-profile moderate --perception-seed 20260805
```

先在手动模式确认车辆和货叉，再按 `P` 进入自动模式。

视觉链路可以单独检查：

```powershell
python .\scripts\run_v9_0_1_1_vision_smoke.py
```

5 局批量示例：

```powershell
python .\scripts\run_v9_0_1_1_batch.py `
  --episodes 5 `
  --difficulty easy `
  --profile moderate `
  --appearance-profile moderate `
  --seed 20260805 `
  --trace-failures
```

## 操作

焦点在仿真窗口内。

| 按键 | 作用 |
| --- | --- |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 转向 |
| `C` | 转向回中 |
| `Space` | 停车 |
| `I` 或 `↑` | 货叉上升 |
| `K` 或 `↓` | 货叉下降 |
| `P` | 手动 / 自动切换 |
| `R` | 重置当前场景 |
| `N` | 抽取新场景并重置 |

鼠标用于转动和缩放 MuJoCo 相机。

## 已记录的结果

下面两组数字来自不同实验，不能加在一起。

种子 `20260805` 的三组随机任务，每组 20 局：

| 工况 | 成功 |
| --- | ---: |
| 中等外观 / 易 | 19 / 20 |
| 中等外观 / 常规 | 19 / 20 |
| 加强外观 / 易 | 19 / 20 |
| 合计 | 57 / 60（95%） |

这三组里，取货视觉、插叉前就绪和终端视觉的参与率都是 100%，渲染失败为 0。取货融合位置的 95 分位误差为 3.9–5.8 cm，航向为 2.9–3.8°，放置位置均方根误差为 3.8–4.7 cm。

同一种子另有 10 局：任务全部完成，位置误差进入 10 cm。其中 1 局航向为 5.07°，超出 5°，这组没有记为精度通过。

五个预先登记的种子（`20260821`、`20260901`、`271828`、`314159`、`8675309`），每个种子 10 局：

| 指标 | 结果 |
| --- | ---: |
| 任务完成 | 约 58% |
| 位置与航向同时达标 | 约 46% |
| 放货超出真值门限 | 6 次 |

强扰动条件下 20 局完成 10 局，只作为边界观察，不并入 57/60。

## 现状

闭环可以运行，也可以重复评分。多种子下的任务完成率和严格精度还没有稳住。新鲜证据的放货规则已经写进 `V9.4.1-E1`，对应单元测试可以通过；这组规则还没有带着新的物理运行记录完成复验，因此不能写成已经提高了放货精度。

堆叠取货、堆叠放置、弱引导和狭窄空间还没有可重复的通过成绩。仿真筛选可以继续用。接到真车之前，要替换相机、实车运动学和线控接口，并先补上多种子复验。

## 目录

```text

configs/       车辆、感知和任务配置

control/       底盘、MPC 与放货核验

simulator/     仿真步进、相机和观测
evaluation/    批量指标
scenarios/     任务采样
scripts/       交互运行、视觉检查和批量测试
tests/         单元测试
```

交互入口是 [`scripts/run_forklift_v9_0_1_1.py`](scripts/run_forklift_v9_0_1_1.py)，默认配置是 [`configs/vehicle_v9_0_1_1.yaml`](configs/vehicle_v9_0_1_1.yaml)。
